### 🔐 [Minimum Messenger](https://github.com/NikitaKHS/minimum-messenger)

Self-hosted end-to-end encrypted messenger designed around a zero-trust server model.

- Client-side E2EE with ECDH, HKDF and AES-GCM
- Multi-device architecture and per-device key management
- FastAPI + PostgreSQL + Redis
- WebSocket realtime delivery
- Transactional outbox pattern
- React + TypeScript frontend
- Docker-based deployment

`FastAPI` `React` `PostgreSQL` `Redis` `WebSocket` `E2EE` `Docker`
